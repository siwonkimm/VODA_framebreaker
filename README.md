# 🔍 ContextLens - 분석 결과 업로드 UI

> 데이터 분석 결과(.xlsx)를 간편하게 업로드하고 아카이빙할 수 있는 웹 인터페이스 | 작성 일자: 26.06.30.

`ContextLens`의 분석 결과 업로드 페이지는 사용자가 진행한 키워드/근연도 분석 데이터 파일과 부가 정보(닉네임, 출처, 설명 등)를 등록하는 프론트엔드 UI입니다.

---

## 📌 주요 기능

1. **사용자 및 출처 정보 입력**
   - **닉네임**: 아카이브에 공개될 작성자 이름 등록
   - **조사 출처**: 버튼 형태의 단일 선택 (뉴스 / 커뮤니티 / 혼합)
2. **상세 분석 정보 작성**
   - **분석 설명**: 카드 뷰에 노출될 핵심 인사이트 요약
   - **수집 건수**: 데이터 분석에 활용된 원천 기사/글 개수 입력
   - **태그**: 쉼표(`,`) 구분 기반의 메타 태그 등록
3. **엑셀 파일 첨부 (Drag & Drop)**
   - `.xlsx` 형태의 근연도 분석 결과 파일 업로드 영역 제공
4. **자동 처리 메타데이터 안내**
   - 업로드 시간, 타겟 키워드 추출, 워드클라우드 시각화 생성 자동화 프로세스 안내

---

## 🛠 기술 스택

- **Markup**: HTML5
- **Styling**: CSS3 (Flexbox, Clean Minimal Design)
- **Icons**: Tabler Icons CDN (`@tabler/icons-webfont`)
- **Typography**: System UI Font Stack (`-apple-system`, `BlinkMacSystemFont` 등)
